# AI Invoice Generator SaaS

An AI-powered SaaS platform that helps freelancers, agencies, and businesses generate professional invoices in seconds. Create, manage, and export invoices effortlessly while leveraging AI to streamline the billing process.

## 🚀 Features

* 🤖 AI-powered invoice generation
* 📄 Professional invoice templates
* 📥 PDF invoice export
* 👤 User authentication & authorization
* 🏢 Customer and client management
* 💰 Automatic tax and total calculations
* 📊 Dashboard for invoice tracking
* 📱 Responsive design for all devices
* 🔒 Secure data management
* ☁️ SaaS-ready architecture

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/kfaridi1947/AI-Invoice-Generater-SaaS.git
cd AI-Invoice-Generater-SaaS
```

### Install Dependencies

Frontend:

```bash
cd client
npm install
```

Backend:

```bash
cd server
npm install
```

### Environment Variables

Create a `.env` file inside the server directory:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_api_key
```

### Run Application

Backend:

```bash
npm run server
```

Frontend:

```bash
npm start
```
